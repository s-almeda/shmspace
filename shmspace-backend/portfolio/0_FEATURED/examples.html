00 — page layout

.piece-page .piece-title .piece-subtitle

wrap everything in <div class="piece-page">. it centers, max-width 1100px, gap 60px between children. use .piece-title + .piece-subtitle for the page header. (you're looking at it.)

01 — bare image (no window)

.piece-bare .w-sm .w-md .w-lg

.piece-bare.w-sm → max-width 300px

.piece-bare.w-md → max-width 500px (default if no modifier)

.piece-bare.w-lg → max-width 700px

02 — bare image side-by-side

.piece-bare.side-left .piece-bare.side-right

.piece-bare.side-left → image on the LEFT, caption on the right. 50/50 split, gap 24px, max-width 780px. markup order is always <img> then <p> — the modifier flips the row direction.

.piece-bare.side-right → image on the RIGHT, caption on the left. same proportions, just mirrored. both side variants auto-collapse to a stacked column under 600px wide.

03 — basic window

.window.piece-window .title-bar .window-body .status-bar

basic_window.exe

combine xp.css's .window with .piece-window. structure: .title-bar (text + controls) → .window-body → .status-bar. default width is min(90vw, 520px).

ready

04 — window sizes

.size-sm .size-md .size-lg

.size-sm

min(80vw, 320px) — good for tight side notes or photo-only windows

.size-md

min(85vw, 460px) — middle of the road, fits most captions

.size-lg

min(92vw, 640px) — full presence, for hero images / longer text

05 — row alignment & tilt

.piece-row.left/.center/.right + .askew-left .askew-right .askew-none

left + askew-left

.piece-row.left pushes me to the left edge. .askew-left tilts -1.2deg.

center (no tilt)

.piece-row.center is the default. no tilt = no askew class.

right + askew-right

.piece-row.right pushes me right. .askew-right tilts +1.2deg. tilt auto-disables under 600px.

06 — body theming

.window-body vs .window-body.dark

light body (default)

default .window-body uses the xp.css beige (#ece9d8) with black text.

dark body

add .dark to .window-body → background #1a1a1a, text #f0f0f0.

07 — image fits inside a window

.piece-img + .contain .tall .short

.piece-img (default = cover)

default: object-fit cover, max-height 60vh. crops to fill the box.

.piece-img.contain

.contain → no cropping. fits whole image, may letterbox.

.piece-img.short

.short → max-height 40vh. for thumbnail-y rows.

.piece-img.tall

.tall → max-height 75vh. for portraits or hero shots.

12 — popup window

.popup-trigger[data-popup="id"] .popup-backdrop#id .popup .popup-close

↑ click the image to open a popup. close it with the × button, by clicking the dark backdrop, or by pressing ESC.

popup_pattern.txt

two parts:

1) on the trigger element, add class popup-trigger and data-popup="some-id".

2) somewhere on the page, add a .popup-backdrop with id="some-id" containing a .popup.window.piece-window. give its close button class popup-close.

the <script> at the bottom of this file wires up open / close / ESC / click-backdrop-to-close.

popup_demo.exe

this is a popup. it can hold anything — image, text, status bar, more buttons.
